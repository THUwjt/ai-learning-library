0 · The contract: compute a future, then use it

A VLA policy maps observations and instructions to actions. An action-conditioned world model instead takes a candidate action and predicts its consequences. A controller can query that model many times before executing anything. This guide follows the actual arrays through that process: encode → condition on action → predict → train or roll forward → choose an action.

The original World Models guide develops the history, objectives and evidence. This companion is an implementation study: what enters each layer, which axes change, which targets are available in training, and which computation must repeat during imagination. It is designed to sit beside the VLA tensor-by-tensor guide.

Reading convention. A released configuration is tied to the cited paper/code. A teaching example fixes a small batch, horizon or observation dimension to make the arithmetic tangible. Do not copy an illustrative dimension into a checkpoint loader. These are source-checked computation traces, not independent training runs or measured hardware benchmarks.

2 · Tensor grammar and the two time axes

2.1 Record transitions before naming a network

Use B independent trajectory segments, T recorded transitions, action width Da, RGB height R and width C. A segment needs T+1 observations if every transition has a next-frame target. We use reward rt and continuation ct for the transition caused by at; some repositories attach these arrays to the next observation, shifting the index by one.

O∈RB×(T+1)×3×R×C,A∈RB×T×Da,r,c∈RB×T×1,(ot,at)⟶(ot+1,rt,ct).\begin{aligned}O&\in\mathbb R^{B\times(T+1)\times3\times R\times C},& A&\in\mathbb R^{B\times T\times D_a},\\r,c&\in\mathbb R^{B\times T\times1},& (o_t,a_t)&\longrightarrow(o_{t+1},r_t,c_t).\end{aligned}Or,c​∈RB×(T+1)×3×R×C,∈RB×T×1,​A(ot​,at​)​∈RB×T×Da​,⟶(ot+1​,rt​,ct​).​

A discrete action may instead be an integer [B,T], converted to an embedding or a one-hot vector. Channel-last implementations use [B,T,R,C,3]. Moving axes is a transpose; reshaping without a transpose generally changes which values belong to a pixel.

2.2 Spatial encoding can parallelize across recorded time

This trick shares encoder weights and batches independent frames. It does not erase temporal order in a subsequent recurrent dynamics model. For a patch encoder, the output may be [BT,P,d] instead of a single vector. Flattening patch features to P·d and pooling them to d are different operations with different information loss.

2.3 An observed posterior and an imagined prior answer different questions

q(zt∣ht,ot)⏟infer state using the real observationp(zt∣ht)⏟predict state without the real observation.\underbrace{q(z_t\mid h_t,o_t)}_{\text{infer state using the real observation}}\qquad\underbrace{p(z_t\mid h_t)}_{\text{predict state without the real observation}}.infer state using the real observationq(zt​∣ht​,ot​)​​predict state without the real observationp(zt​∣ht​)​​.

A model can reconstruct held-out frames accurately while rolling out poorly: reconstruction sees the answer through the encoder, whereas free rollout must supply its own next latent. Keep three evaluations distinct: reconstruction, one-step prediction with real history, and open-loop multi-step prediction. Resetting with a real frame at every step measures a different computation from a long dream.

2.4 Environment time is not denoising time

Let t index environment transitions, j index diffusion solver steps within one transition, H the number of imagined transitions, and N the number of candidate plans. A diffusion simulator can require H×J denoiser evaluations along a single rollout. A token simulator can require H×K causal token emissions. Neither J nor K is the number of robot actions executed.

candidate actions: [B,N,H,Da],candidate latent states: [B,N,H+1,dz].\text{candidate actions: }[B,N,H,D_a],\qquad\text{candidate latent states: }[B,N,H+1,d_z].candidate actions: [B,N,H,Da​],candidate latent states: [B,N,H+1,dz​].

The planner may fold B·N into the batch axis, evaluate independent candidates together, and keep H sequential because every future state depends on its predecessor. A model trained to predict a whole future block can have different parallelism; do not assume all video models use the autoregressive rollout described here.

2.5 Loss reduction is part of the algorithm

A sum over pixels and a mean over pixels differ by 3RC. The same is true for sums versus means over categorical variables, latent dimensions and rollout time. Gradient scaling changes when these losses are combined. We explicitly identify the important reductions and use simplified mathematical expressions only where their scope is stated.

Lmasked=∑b,tmb,tℓb,tmax⁡(1,∑b,tmb,t),sg⁡(x)=x in the forward pass,∂sg⁡(x)∂x=0.\mathcal L_{\mathrm{masked}}=\frac{\sum_{b,t}m_{b,t}\ell_{b,t}}{\max(1,\sum_{b,t}m_{b,t})},\qquad\operatorname{sg}(x)=x\ \text{in the forward pass},\quad\frac{\partial\operatorname{sg}(x)}{\partial x}=0.Lmasked​=max(1,∑b,t​mb,t​)∑b,t​mb,t​ℓb,t​​,sg(x)=x in the forward pass,∂x∂sg(x)​=0.

Padding, episode resets and terminal flags must agree with the transition convention. A time-limit truncation is not necessarily an absorbing terminal state; continuation targets and bootstrapping depend on the environment contract. Stop-gradient preserves a value while blocking a particular learning path—it does not freeze every use of the shared network.

3 · The foundation: World Models = VAE + MDN-RNN + controller

The original World Models (Ha & Schmidhuber, 2018) separates three questions: how to compress the current image, how to predict the next compressed observation, and how to choose an action. This is a useful first trace because no transformer is involved. We use the authors’ CarRacing implementation: 64 × 64 RGB, 32 latent coordinates, 3 action coordinates, 256 LSTM units, and 5 mixture components per latent coordinate. Batch and sequence sizes below remain symbolic. These are not the VizDoom configuration.

Implementation detail: these are coordinatewise mixtures. They are not one five-component full-vector mixture with one shared component index for all 32 coordinates. Coordinates share the LSTM conditioning, but the conditional output distribution factorizes over coordinates. Training minimizes negative log likelihood, using log-sum-exp over the five component log densities; averaging over coordinates versus summing changes its overall scale.

3.3 Close the loop

The default MODE_ZH controller observes the current latent and recurrent memory: [zt;ht] has 32 + 256 = 288 features, mapped to three controls with action-specific output transformations. In the original work the controller is optimized with evolution strategies. It is not the MDN trained to output an action. In a real environment, encode each newly observed image; in a dream rollout, feed the model’s sampled next latent into the next step. This replacement of posterior evidence with a model sample is where accumulated model error enters.

Numerical check: one mixture coordinate

For a two-component teaching example with weights (0.75,0.25), means (−1,+1), and standard deviations (0.2,0.2), the conditional mean is −0.5. Yet −0.5 is 2.5 standard deviations from the first mode and 7.5 from the second. Always emitting the mean produces a value that is unlikely under the learned multimodal distribution. Sampling preserves the alternatives. This illustrates why an MDN was used instead of plain next-latent MSE; it does not establish that every latent coordinate needs a mixture.

4 · DreamerV3: an RSSM, from pixels to imagined actor training

Dreamer joins image representation and dynamics learning. Its recurrent state has two parts: a deterministic memory h and a stochastic latent z. During observation, an image-conditioned posterior corrects the model; during imagination, a prior supplies the missing observation. An actor learns on the imagined state sequence, so a rollout usually need not decode pixels.

Pin the implementation before counting dimensions

This walkthrough uses the official DreamerV3 repository at e3f02248, inspected September 2026, and its default / size200m configuration. It is an updated implementation, not a claim that every detail equals the original 2023 paper. In particular this configuration uses 32 categorical variables with 64 classes each and an 8,192-wide deterministic state; the familiar 32 × 32 latent appears in earlier configurations. We choose B=2, T=4, one 64 × 64 RGB observation, no vector observations, and a 6-dimensional continuous action as explicit teaching choices. The network widths below are code-derived.

There are 32 one-hot selections, not one categorical selection from 2,048 classes. The joint latent has 6432 possible assignments, though learning and finite capacity do not guarantee use of all of them. Its dense training representation stores 2,048 entries, whereas a lossless packed index representation would need only 32 × log₂64 = 192 bits. The actual network computes on dense categorical features; it is not a 192-bit hardware implementation.

4.3 Advance deterministic memory: the exact block-GRU path

At each of the four observed time steps, prior h is [2,8192], prior z is [2,32,64], and previous action is [2,6]. At an episode reset, carried state and previous action are zeroed before transition. Time alignment matters: the transition into state t uses at−1, not the action selected after observing xt.

  1. Flatten z to [2,2048]. Normalize action coordinates by max(1, |a|) using a stopped denominator.
  2. Apply separate dense projections h: 8192 → 1024, z: 2048 → 1024, a: 6 → 1024; each uses RMS normalization and SiLU. Concatenation yields [2,3072].
  3. Repeat this common input across 8 groups: [2,8,3072]. Reshape prior h into [2,8,1024] and concatenate within each group: [2,8,4096]. Flatten only for the block-linear API: [2,32768].
  4. A groupwise linear layer maps eight independent 4096 → 1024 blocks, giving [2,8192], followed by normalization and SiLU.
  5. A second block-linear emits [2,24576], logically [2,8,3072]. Split each group into reset, candidate and update preactivations; each re-flattens to [2,8192].

These are the code’s gate conventions: here u weights the candidate. The name “GRU” alone would not specify the −1 update bias, the reset placement, the grouping, or the tensor widths. Grouping also changes parameter cost: the 8-block 4096 → 1024 map has 8 × 4096 × 1024 = 33,554,432 weights, versus 32768 × 8192 = 268,435,456 for a dense map of the same flattened input/output sizes, excluding biases and normalization parameters.

4.5 Decode only the quantities needed by the loss or policy

Flatten h and z into feature [2,4,10240]. Reward and continuation heads each have one 1,024-wide hidden layer. The reward head emits 255-bin distribution logits [2,4,255], not just a scalar; its distribution exposes a scalar prediction [2,4]. The continuation head supplies one Bernoulli prediction per time step. Actor and value heads each have three 1,024-wide hidden layers; the value output also has 255 bins. The continuous actor produces distribution parameters for six action coordinates and samples [2,4,6].

For image reconstruction, the default decoder is more structured than a single dense feature projection:

  1. Flatten B and T: h [8,8192], z [8,2048].
  2. Project h through an 8-group block-linear to 4096 entries and rearrange to [8,4,4,256]. Project z through 2048 → 2048 → 4096, then reshape to the same spatial tensor. Add the branches, normalize, activate.
  3. Repeat each spatial axis by two and convolve, giving [8,8,8,256] → [8,16,16,192] → [8,32,32,128].
  4. Final repeat + convolution + sigmoid gives [8,64,64,3]; restore [2,4,64,64,3]. Reconstruction targets are x/255, even though encoder inputs were x/255 − 0.5.

The image squared-error sum reduces height, width and channel axes, leaving loss [2,4]. Reward, continuation and KL losses also retain [2,4] until the final averaging. This makes time and sample weighting explicit.

The two KL values are numerically equal before flooring, but their computational graphs differ. The dynamics loss teaches the prior to predict the observation-informed latent. The representation loss asks the posterior not to encode information that is unnecessarily difficult to predict, while reconstruction/reward objectives prevent trivial collapse. Stop-gradient freezes that distribution branch for the particular KL term; parameters shared elsewhere may still receive gradients through other paths. The 1-nat floor is applied after summing over categorical variables. Below the floor that term has zero gradient, not a constant pressure toward one nat.

Small calculation. For one two-class teaching variable q=(0.8,0.2), p=(0.5,0.5), KL = 0.8 ln1.6 + 0.2 ln0.4 ≈ 0.192745 nats. If ten independent variables have those probabilities, their joint KL is 1.92745 nats, so the 1-nat floor is inactive. In the dynamics branch, the derivative with respect to a prior softmax logit is p−q: (−0.3,+0.3) per variable, before loss averaging and any uniform-mix chain rule. Gradient descent increases the first logit, bringing the prior toward the posterior. In the representation branch that prior-logit gradient is stopped.

4.7 Imagine 15 transitions from every replay state

The pinned agent defaults to starting imagination from every retained replay state. With B=2,T=4, merge them into an imagination batch N=BT=8. These are eight distinct starting states, not one rollout of length eight.

Therefore “Dreamer trains in a differentiable world model” must not be turned into the blanket claim that this implementation backpropagates the actor’s reward gradient through every imagined transition. What changed relative to the VAE + MDN-RNN?

The original pipeline predicts a latent produced by a separately trained frame VAE. The RSSM learns an observation-informed latent jointly with memory, reward and reconstruction. Its prior and posterior have identical tensor contracts, enabling observed and imagined transitions to share code. The decoder supplies a learning signal; the compact state, not a rendered video, is the interface used by the actor.

5. Roll out one frame with a KV cache

  1. Encode the real starting frame to [B, 16] and prefill the transformer cache with those tokens.
  2. The actor chooses action [B, 1]. One cached transformer call yields reward/end distributions and the first future visual-token distribution [B, 1, 512].
  3. Sample that code, feed it back, and obtain the next code distribution. Continue until all 16 codes exist.
  4. The official environment makes 17 calls per full transition: one action call plus 16 visual-token calls. The last visual-token call inserts the final code into the cache; it does not sample a 17th visual code.
  5. Look up [B, 16, 512], reshape [B, 512, 4, 4], decode to [B, 3, 64, 64], map back to [0, 1] and clamp. The actor can now choose the next action from the generated image.

Per-layer cached K and V each have shape [B, 4, Npast, 64]. For a new token, the score tensor is [B, 4, 1, Npast + 1], rather than a full square. The configured capacity is 340 tokens. On overflow the official environment re-prefills only the latest frame’s 16 codes; it does not maintain an indefinitely sliding full-history cache. See the rollout loop. This is an example of why an abstract maximum-context claim does not fully describe effective rollout memory.

Where error enters: x → codes → reconstructed x can erase small objects before dynamics prediction begins. Even a perfect categorical dynamics model cannot recover information absent from its conditioning codes. Increasing K from 16 to 64 preserves more visual information but changes each frame from 17 to 65 sequence positions and increases serial generation work. DIAMOND changes this representation trade-off by generating pixels directly.

What is being modeled? TD-MPC2 learns enough dynamics to predict reward and long-term value, and uses that latent model to search over actions. 3. Why 101 reward logits represent one scalar

The default support has 101 equally spaced bins between −10 and +10 in symlog space, spacing 0.2. A target between bins is linearly split over its two neighbors. Cross-entropy trains this soft target; decoding averages the bin locations and then applies symexp. Averaging physical-space bin values would be a different decoder.

5. Planning: the candidate axis becomes the compute batch

For one environment, the default planner uses N=512 candidates, H=3, six refinement iterations, 64 elites and 24 policy-generated candidate trajectories. With six action coordinates:

  1. Encode the real state: [1,24] → [1,512]. Repeat for candidates: [512,512]. This copy supplies the same initial state to every plan.
  2. Sample a candidate-action tensor [3,512,6]. The first 24 candidates come from rolling out the policy prior; the other 488 are Gaussian samples around the current mean [3,6], clipped to [−1,1].
  3. At each t, actions [512,6] concatenate with states [512,512]. Predict rewards [512,101] → [512,1] and next latents [512,512]. Repeat for three sequential transitions.
  4. Add a discounted terminal Q estimate at the final latent. The planner uses the average of two randomly selected Q-heads here, whereas TD targets use the minimum. Scores have shape [512,1].
  5. Keep the 64 highest-scoring plans: [3,64,6]. Refit an exponentially weighted mean and standard deviation, both [3,6]. Repeat six times.
  6. The implementation samples an elite according to its final normalized score, takes its first action [6], and adds exploration noise outside evaluation mode. It does not simply execute the entire mean sequence. Warm-start the next call by shifting the mean, then observe and replan.

8 · V-JEPA 2 → V-JEPA 2-AC: predict useful features, then plan actions

This family answers a different question from a video generator: what will the scene’s learned representation become if I take this action? It does not produce future RGB pixels. The distinction is visible in the output type: a spatial feature map with 1,408 channels, rather than a three-channel image. Base V-JEPA 2 learns representations by completing masked video features; V-JEPA 2-AC adds a separately trained, action-conditioned transition predictor. Action-free masked prediction alone does not provide an interface for evaluating counterfactual robot commands.

Choosing a candidate introduces another failure mode

A planner selects the most attractive prediction out of many possibilities. It may therefore select a trajectory with unusually optimistic model error. Increasing candidate count improves optimization of the learned model's score; it does not automatically improve the real trajectory. Diagnose this with held-out action-conditioned prediction, free rollout, value calibration, and executed return, rather than visual quality alone.

VLA and world models fit together. A VLA can propose candidate action chunks [B,N,H,Da]. A world model predicts consequences for those candidates. A goal cost or value head ranks them, and the robot executes a short prefix. This combination still needs matched action units, timestamps, observation transforms and horizon semantics; shape compatibility alone is insufficient.
